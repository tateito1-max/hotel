# 冒険者ギルド運営シミュレーション 仕様書

- 版数: 0.12（ドラフト）
- 最終更新: 2026-07-21
- ステータス: 単一ダンジョン制覇型に前提を確定。主要システムの方針確定 / 経済・判定・遭遇の初期値たたき台あり（§15）

---

## 1. コンセプト

> 町外れに口を開けた**単一の大迷宮（メガダンジョン）**。プレイヤーはこれを制覇するために
> 設立された冒険者ギルドの**ギルドマスター**。冒険者を雇い、迷宮に潜らせ、
> 持ち帰った富をやりくりしてギルドを強化し、**最深部の主の討伐＝迷宮制覇**を目指す
> ターン制の経営シミュレーション。

- **ダンジョンに潜らせることがゲームの主活動**。地上はあくまで経営拠点
- 一番の楽しさ（コア体験）: **経営・数値管理**、とりわけ**編成パズル**
  - 「どの階へ、何をしに、誰を何人潜らせ、何に投資するか」を毎ターン判断する意思決定の手応え
  - リスク（全滅・死亡・蘇生費）とリターン（回収品・名声・踏破）の天秤
- 冒険者は多彩な能力を持つ「経営資源」。戦闘職だけでなく**非戦闘職**（荷物持ち・学者・採掘師など）が
  遠征の目的によっては主役になる
- **普遍的な最適解（最強編成・最適人数）は存在させない**。階層・目的・手持ちの人材の
  噛み合わせで、毎回考える必要がある状態を目指す

## 2. ゲームの基本構造

### 2.1 進行形式

- **ターン制。1ターン = 1日**
- ターン中はプレイヤーの操作フェイズ（遠征計画・編成・投資）→「日を進める」で解決フェイズ
- リアルタイム要素・放置要素は入れない

### 2.2 コアループ

```
① 遠征目標を決める — どの階へ、何をしに
   ├ 自主遠征: 攻略（未踏階の踏破）/ 採掘・採取 / 調査 など目標を自由に設定。
   │           収入は回収品のみ。失敗してもペナルティはない（損害は自分持ち）
   └ 依頼受注: 外部からの委託（素材納品・調査委託・討伐委託・救出）。
               固定報酬＋名声が得られるが、失敗すると違約金
        ↓
② パーティを編成して派遣（人数・構成・前衛後衛・補給・行動方針）
        ↓
③ 日を進める → 潜行は全自動で進行、遭遇も自動解決、帰還まで指示不可
        ↓
④ 帰還報告 → 報酬・名声・回収品を獲得（損害: 負傷・死亡・違約金）
        ↓
⑤ 収入で 雇用 / 施設投資 / 装備支援 → より深い階へ潜れる態勢に → ①へ
```

### 2.3 勝敗・ゲームの終わり

- **勝利条件: 最深部の主を討伐する（迷宮制覇）**
- **敗北条件**: 資金がマイナスのままターン終了時の支払い（給料・維持費）ができない → 倒産
- クリア後はフリープレイ継続可
- （旧仕様の「ギルドランクS到達」は勝利条件から外し、ランクは進行ゲートに役割変更。§11）

## 3. ダンジョン

### 3.1 構造

- 階層制の単一大迷宮。**階層帯**で難易度が区切られる（階数はたたき台）:

| 階層帯 | 階 | 難易度帯 | 特色の例 |
|---|---|---|---|
| 浅層 | 1〜10F | E〜D | 洞窟・旧坑道。鉱脈階、地底湖 |
| 中層 | 11〜25F | C〜B | 古代遺構・大空洞。遺構階（学術調査向き）、魔物の巣 |
| 深層 | 26〜40F | A | 魔境。高価値資源と凶悪な主 |
| 最深部 | 41〜50F | S | 最後の主が待つ |

- 各階は**環境タグ**（暗所・狭隘・水場・大空洞…）と**資源**（鉱脈・遺構・群生地…）を持つ。
  何があるかは**踏破して初めて判明**する → 攻略が稼ぎ先の選択肢を増やす
- 環境タグは判定に作用する（狭隘→戦闘の前衛席減、暗所→夜目特性が活きる 等）

**生成方式: ルール付きランダム生成（確定事項）**

- 階の内容（環境タグ・資源・難所・敵の構成）は**シードから決定論的にランダム生成**する。
  プレイごとに迷宮の中身が変わり、リプレイ性を持たせる
- ただし完全ランダムではなく、**階層帯ごとの生成ルールテーブル**に従う:
  - 帯ごとに環境タグ・資源・敵のプールと出現重みを定義（浅層は旧坑道・鉱脈が出やすい、
    中層は遺構が混ざる、など雰囲気の一貫性もここで作る）
  - **深い帯ほど「難所」の出現率・同時付与数が増える**
- **難所** = 通過・作業を困難にする地形タグ。例:
  崩落地帯（罠課題を追加）、毒沼（耐久判定・食料消費増）、氷結（器用判定・進行遅延）、
  暗黒（暗所の強化版。夜目がないと大幅ペナルティ）、断崖（運搬量制限）など。
  難所は課題リストへの追加・席数の圧縮・コスト増として機械的に効く
- 主の配置は帯境界の階（たたき台: 5F/10F/25F/40F/50F）に固定で置く（ルール側の保証）。
  中間階への追加配置はランダム
- 生成はゲーム開始時にシードから全階分決定するが、内容は踏破まで非公開
  （シード指定プレイで同じ迷宮を再挑戦できる。§13 の乱数方針と整合）

### 3.2 到達階層と攻略

- ギルドは**最深到達階**を持つ。未踏の階へは「攻略遠征」で踏破して進む
- 潜れるのは到達階層＋その攻略対象のみ。**深く潜るにはまず道を拓く**
- 一部の階には**主（フロアボス）**が居座り、討伐するまで先へ進めない（進行のマイルストーン）。
  最深部の主の討伐がゲームクリア
- 深い階ほど移動日数がかかる（遠征の所要日数・食料に直結）。
  中継拠点（前線キャンプ）による短縮は拡張候補（§16）

### 3.3 階層危険度

- 旧「経路危険度」を階層帯に対応させる（数値は §15.4 で検証済みのものを流用）:
  浅層上部10% / 浅層下部20% / 中層35% / 深層以降50%（1日あたり基礎遭遇率）
- 深いほど敵戦力・課題値・回収品価値が同時に上がる

## 4. キャラクターシステム

### 4.1 能力の3層構造＋種族・性格

キャラクターは「**種族 × 性格 × 能力値 × スキル × 特性**」で表現する。
職業（クラス）は固定の枠ではなく、**スキル構成に付いた肩書き**として扱う。

**① 基礎能力値（6種、1〜20）**

| 能力値 | 主な用途 |
|---|---|
| 筋力 | 近接戦闘、運搬量 |
| 耐久 | 生存性、負傷しにくさ、長期任務への耐性 |
| 器用 | 罠解除、採掘・工作、射撃 |
| 知力 | 学術調査、鑑定、魔法 |
| 感知 | 索敵、危険察知、隠密 |
| 魅力 | 交渉、士気、指揮の通り |

**② スキル（Lv0〜10、能力値と組み合わせて判定に使う）**

| 系統 | 例 |
|---|---|
| 戦闘系 | 剣術、弓術、攻撃魔法、盾防御 |
| 探索系 | 斥候・隠密、罠解除、追跡、地図作成 |
| 学術系 | 考古学・古代語、鑑定、薬学 |
| 技能系 | 採掘、採取、運搬、料理、応急手当、鍛冶 |
| 対人系 | 交渉、指揮、荷役管理 |

**③ 特性（トレイト。パッシブな個性）**

例: 夜目（暗所ペナルティ無効）、頑健（負傷日数短縮）、大食い（補給消費+50%）、
カリスマ（同行者の士気+）など。プラスとマイナスの両方を持たせ、契約料と釣り合わせる。

### 4.2 種族

種族は「能力値の傾向＋固有特性」を与える。ダンジョンの環境タグと噛み合わせて編成の幅を作る。

| 種族 | 能力傾向 | 固有特性の例 | 出現率 |
|---|---|---|---|
| 人間 | 平均的・成長が速い | 器用貧乏（全スキル経験+10%） | 高 |
| エルフ | 感知・知力+ / 筋力− | 夜目、精霊感応（魔法系判定+） | 中 |
| ドワーフ | 筋力・耐久+ / 感知− | 坑道慣れ（採掘+、狭隘ペナルティ無効）、酒豪 | 中 |
| 獣人 | 筋力・感知+ / 知力− | 嗅覚追跡（斥候+）、大食い | 中 |
| 小人族 | 器用・感知+ / 筋力− | 小さな体（隠密+、運搬量−） | 低 |
| 竜人 | 筋力・耐久++ / 魅力− | 鱗の守り（負傷しにくい）、契約料高騰 | 稀 |

- 出現率はレア度を兼ねる。珍しい種族は総じて強力だが契約料が高い（§5）
- MVPは3種族（人間・エルフ・ドワーフ）から始める

### 4.3 性格

性格は**全自動解決中の行動傾向**として効く（派遣後に指示できない設計だからこそ、
「誰を送ったか」が道中の挙動を決める要素になる）。

| 性格の例 | 自動解決への作用 |
|---|---|
| 勇敢 | 遭遇時に戦闘を選びやすい。撤退ラインが甘くなる |
| 臆病 | 危険察知で回避・撤退寄り。主クラス遭遇時の生存率は高い |
| 慎重 | 罠・危険察知にボーナス。進行がやや遅い（所要日数+） |
| 強欲 | 回収量にボーナス。危険でも回収を優先してしまう |
| 協調的 | 大所帯でも士気が保たれる。統率ペナルティを緩和 |
| 一匹狼 | 少人数で能力+。大所帯では士気低下要因 |

- 行動方針（慎重/標準/強行。§6.1）はパーティ全体の「命令」、性格は個人の「従い方」。
  強行方針でも臆病者は逃げ腰、慎重方針でも勇敢な者は突っ込む——ままならなさを演出する
- MVPでは1人1性格タグ・軽い補正のみ。性格同士の相性（人間関係）は拡張候補

### 4.4 職業（肩書き）の例

応募者は肩書き付きで現れるが、実体はスキルセット。育成次第で複合職化も可能。

- **戦闘職**: 戦士、弓手、魔導士、盾持ち
- **探索職**: 斥候、罠師、狩人
- **非戦闘職**: **荷物持ち**（運搬特化・回収量を増やす）、**学者**（遺構調査の成果品質を上げる）、
  **採掘師**（採掘遠征の主役）、治癒師、料理人（長期遠征の補給効率・士気）、交渉人

### 4.5 その他

- 所在: 待機 / 派遣中（身体の状態とは別軸で管理）
- 身体の状態: 健康〜死亡までを一本の「状態異常ラダー」で管理（§4.6）
- 報酬: **報酬分配が主、基本給が従**（詳細は §9 給与体系）。未払いは士気低下→離脱
- 成長: 遠征で実際に使ったスキルに経験が入る（使った能力が伸びる）

### 4.6 状態異常ラダー — 負傷・死亡・蘇生（確定事項）

**負傷と死亡（死体の状態）は、生死をまたぐ一本の「状態異常ラダー」として統合して管理する:**

```
健康 → 軽傷 → 重傷 ‖ 健全な死体 → 損傷 → 白骨 → 灰 → 魂魄 → 魂の破片
（‖ が生死の境界。左側は生存中、右側は死亡中）
```

- **生存側は時間で回復する**（重傷→軽傷→健康。医務室・治癒師で短縮）
- **死亡側は放置で悪化する**（回収されず現地に残された死体は **5ターンごとに1段階悪化**。仮置き）
- 回収してギルドに安置した死体は悪化しない（死亡中も基本給を払って蘇生時期を選べる、
  という §9.1 の設計と整合させるため）
- 派遣中に死亡した場合、死体は運搬対象になる（運搬力を圧迫する）。
  持ち帰れなければ現地に残す＝悪化が始まる

**負傷段階の扱い**

| 状態 | 効果（たたき台） |
|---|---|
| 軽傷 | 全能力 −25%。派遣は可能（続投させるか休ませるかの判断が生まれる） |
| 重傷 | 派遣不可。回復まで約10日（軽傷は約3日。医務室で短縮） |

**死亡と蘇生の基本方針: 死亡はするが、蘇生可能。完全なロストは「プレイヤーが能動的に解雇した場合」のみ。**

- 死亡したメンバーは名簿に「死亡」状態で残り続ける。蘇生するか、解雇（＝弔って手放す）するかは
  プレイヤーの判断。システム側から勝手に消えることはない
- 死亡直後の初期状態は死因で決まる（通常の戦死→健全〜損傷、ドラゴンの炎→灰、精神攻撃→魂魄 など）
- 死体状態が悪いほど: 蘇生費用が跳ね上がる / 必要な術者・施設の格が上がる / 失敗リスクや後遺症の可能性

**蘇生の手段（確定事項）**

| 手段 | 条件 | 費用感 |
|---|---|---|
| 地上の蘇生施設 | **ゲーム開始時から利用可**。操作フェイズ中に実行。死体等が手元にあること | **割高**。誰でも頼れる標準の受け皿 |
| 自前の回復術師（地上） | 蘇生可能な回復術を使える**生存中の**メンバーがいること | **割安**。術者の格が扱える死体状態の上限を決める |
| ダンジョン内での蘇生 | 強力な回復術師がそのパーティに同行していること | その場で復帰できるが、術者の格と死体状態による制限が大きい |

- 「高いが常に頼れる施設」と「安いが人材依存の自前蘇生」の2本立て。
  蘇生術師を雇い維持すること自体が投資判断になる（その術師が死ぬと施設頼みに戻る）

**全滅時の扱い**

生還者がいないため死体は迷宮内に残される。回収手段は2系統：

1. **救出・回収遠征**: 別パーティを編成して現地の階へ派遣する。
   日数が経つほど死体の状態が悪化するため、急ぐか、諦めて後で高コスト蘇生するかの判断になる
2. **降霊術**: 大金を払って魂を呼び、魂魄状態からの蘇生を行う。死体回収は不要だが最高コスト帯

- 全滅は「取り返しのつかない失敗」ではなく「**巨額の出費と時間を要する経営危機**」として設計する。
  倒産（§2.3）に至る主要因のひとつになる想定

### 4.7 装備と消耗品（確定事項）

**方針: 簡潔に。スロット3つ＋消耗品。強化・クラフトはなし（拡張候補にも当面入れない）。**

| スロット | 効果 |
|---|---|
| 武器 | 戦闘系判定にボーナス。近接武器→前衛適性、弓・杖→後衛適性と対応（§7.1） |
| 防具 | 負傷・死亡判定の軽減。重量がある（運搬力を消費） |
| アクセサリー | **耐性・特殊効果**。難所・環境タグへの対策枠（防毒の護符→毒沼無効、暗視のランタン→暗黒対応、氷除けの外套→氷結耐性 など）。種族特性と同系統の効果を後付けできる枠 |

- **アクセサリーは難所対策の鍵**（§3.1）。深層の難所に挑むには対応アクセの確保が攻略要素になる
- 装備は**ギルド資産**。キャラに割り当てておき（持たせっぱなし）、編成画面から付け替えできる
- 入手: 地上の店での購入＋**ダンジョンドロップ**（回収品として持ち帰る。使うか売るか）
- **死亡者の装備は死体と共に現地に残る**。装備ごと回収するのも救出・回収遠征の動機になる

**消耗品（回復アイテム）**

- 遠征に持たせる消耗品枠。全自動解決中に行動方針に従って自動消費される
- 例: 回復薬（負傷の悪化を1段階防ぐ/死亡判定を重傷に軽減するチャンス）、解毒薬（毒沼等の被害軽減）
- 食料と同様に重量を持ち、運搬力を消費する（積むほど回収可能量が減る）
- MVPは回復薬1種から始める

**回収品の使い道（確定事項）**: ①素材・遺物・鉱石 → 換金・納品依頼、②装備品ドロップ → 使うか売るか、
③回復アイテム → 使うか売るか。クラフト・施設強化素材には**しない**（簡潔さ優先の設計判断）。

## 5. 雇用 — 応募者リスト（人材ガチャ）

- 雇用は**応募者リスト**から行う。リストには常時数名の候補が載り、**7ターンごとに更新**される
- 候補者は「種族 → 性格 → 職業テンプレート → 能力・スキルのロール → 特性」の順で生成される
- **名声値が候補の質の分布を決める**: 名声が高いほど、能力ティアの高い応募者・
  珍しい種族・希少スキル（蘇生術など）の出現率が上がる
- **契約料（雇用一時金）と基本給は応募時の能力・種族レア度から自動算出**される。
  つまり名声が上がると「**強いが高い**」候補が並ぶようになり、
  資金と相談しながら引くか見送るかを決める人材ガチャになる
- 見送った候補は次回更新で入れ替わる。「今いる B級剣士を高値で引くか、次の更新に賭けるか」
  という判断を作る
- 候補の質・数は酒場（§10）でも補正される。広告費による即時更新（リロール）は拡張候補

## 6. パーティと派遣

### 6.1 派遣は「送り出したら全自動」（確定事項）

- **派遣後のパーティには一切の追加指示を出せない。帰還（または全滅）まで全自動で進行する**
- 道中の遭遇・トラブルもすべて自動解決され、プレイヤーは日次のイベントログで経過を知るのみ
- したがって、プレイヤーの意思決定はすべて**派遣前**に集約される：
  - 誰を何人送るか（編成・前衛後衛の割り当て）
  - 食料・装備をどれだけ持たせるか（補給）
  - **行動方針**の指定（慎重＝危険を察知したら撤退優先 / 標準 / 強行＝多少の損害でも任務継続）
- 行動方針は自動解決時の判断基準（撤退ライン・遭遇時の対応傾向）として機能し、
  個々のメンバーの**性格**（§4.3）がそれに揺らぎを与える
- この仕様の狙い: 「見送ったあとは祈るだけ」の緊張感と、帰還報告を開ける楽しみ。
  経営ゲームとしての判断密度を編成画面に集中させる

### 6.2 人数の設計方針

- **システム上の最大: 20人／遠征**（UI・処理はこれを前提に設計する）
- **「多いほど良い」にはしない。ただし一律のペナルティで最適人数を固定もしない。**
  複数の独立したコスト系統を用意し、遠征の性質によって効いてくるコストが変わるようにする。
  → 「この遠征なら大所帯で圧殺」「この遠征は精鋭3人」「これは戦力2人＋荷物持ち6人」が
  それぞれ正解になり得る状態が設計目標

### 6.3 人数のメリット / コスト

メリット: 各判定に参加できる頭数 / 総運搬力の増加→回収報酬増 / 冗長性（負傷者が出ても継続）

| コスト系統 | 内容 | 効きやすい遠征 |
|---|---|---|
| **経済** | 報酬は参加者に分配される（§9）ため、頭数を送るほどギルドの取り分率が下がる。食料も人数×日数で増加 | すべて（常時の圧力） |
| **隠密・遭遇** | 大所帯は目立つ。遭遇頻度が緩やかに上がり、**主クラスとの遭遇率**が上がる | 深い階・未踏階 |
| **補給** | 消費食料 = 人数×日数。食料は運搬力を圧迫し、**積んだ分だけ戦利品を持ち帰れない** | 深い階への長期遠征 |
| **依頼側の制約** | 隠密調査は人数上限、氾濫迎撃は人数下限など | 依頼による |
| **統率** | 一定人数を超えると指揮スキルがないと士気・判定にペナルティ | 大所帯全般 |

**遭遇危険度（方針確定）**: 遭遇は全自動で解決されるため、人数増による遭遇「頻度」の上昇は
マイルドで良い。大所帯を実際に締めるのは**遭遇の「質」＝主クラスとの遭遇率**と、
頭割り分配による経済圧力。斥候による頻度緩和は上限つき（「20人で隠密潜入」は不成立）。
具体式と係数は §15.4。

### 6.4 運搬力と補給

- 各メンバーは運搬力を持つ（筋力＋運搬スキル＋装備で決まる）
- パーティ総運搬力から食料・装備・消耗品の重量を引いた残りが**回収可能量**
- 回収品（素材・遺物・鉱石・装備品・回復アイテム）は持ち帰った分だけ換金・納品・利用できる（§4.7）
  → 「たくさん回収したいから荷物持ちを連れて行く」が数値上で成立する

## 7. 戦闘 — 前衛・後衛

### 7.1 戦列（前衛/後衛）

- 編成時に各メンバーを**前衛 / 後衛**に割り当てる（自動推奨あり。非戦闘員は自動的に後衛の後ろ＝**輜重**扱い）
- 戦列適性はスキルから導出: 盾防御・剣術など近接系→前衛適性、弓術・攻撃魔法など射撃/術系→後衛適性。
  両方持てばどちらにも立てる
- 戦闘の席数型（§8.3）は**前衛席＋後衛席**に分解される。席数は階の環境タグで決まる
  （狭隘な通路: 前2+後2、大空洞: 前6+後6 など）

### 7.2 戦列バランスのルール

- **有効後衛数 ≤ 前衛数 × 2**。超過した後衛は寄与半減（壁がなければ弓も魔法も撃ち続けられない）
- 戦闘敗北時の負傷・死亡は前衛に偏る。ただし**前衛が崩れた（全滅・不足）状態では
  後衛と輜重が最も危険**になる（荷物持ちを守るためにも前衛の頭数が要る）
- 適性のない者を前衛に立てることは可能だが、寄与が低く負傷リスクが高い
- → 「前衛2枚は最低限」「採掘遠征でも護衛の壁を何枚積むか」という編成判断を作る

## 8. 遠征と依頼

### 8.1 遠征の構造

自主遠征・依頼とも、実体は「目標（階と目的）＋課題リスト」を持つ遠征として統一的に扱う。

| 項目 | 内容 |
|---|---|
| 目標 | 対象階と目的（攻略 / 採掘・採取 / 調査 / 討伐 / 救出・回収） |
| 課題リスト | 例:「戦闘脅威 30（前2+後2）」「罠 10」「古代語解読 15」「採掘量目標 200」など複数 |
| 行程 | 対象階までの移動日数＋現地作業日数。階層危険度・環境タグ |
| 人数条件 | 上限・下限・推奨（ない遠征も多い） |
| 報酬 | 依頼: 固定報酬（資金＋名声）＋回収品 / 自主遠征: 回収品のみ（攻略は名声大） |
| 失敗時 | 依頼: 違約金＋名声低下 / 自主遠征: ペナルティなし（損害は自分持ち） |
| 期限 | 依頼は受注しないまま n 日で掲示板から消滅 |

### 8.2 遠征の例（編成の多様性を生む見本）

- **未踏階の攻略遠征（自主）**: 課題=[戦闘, 罠, 地図作成]。バランス型精鋭。踏破すると名声と新resource
- **遺構階の学術調査（依頼）**: 課題=[護衛戦闘, 罠, 古代語解読]。学者必須級。
  人数を増やすと遺構の主を起こすリスク（隠密系コストが支配的）
- **鉱脈階の採掘遠征（自主/依頼）**: 課題=[採掘量目標, 軽微な魔物]。採掘師の頭数と運搬力が物を言う。
  大所帯が正解になりやすいが、分配と食料で利益率との勝負（経済・補給コストが支配的）
- **静穏調査（依頼）**: 課題=[隠密, 観察]。人数上限4。少数精鋭でしか受けられない
- **氾濫の迎撃（依頼）**: 課題=[戦闘 大（前6+後6）]。人数下限8。頭数と指揮スキルが必要
- **行方不明パーティの救出（依頼/自主）**: 課題=[戦闘, 追跡, 運搬（死体・生存者）]。時間圧力あり（§4.6）

### 8.3 課題への人数寄与 — 課題ごとの集計型（確定事項）

課題判定に使う「パーティ該当能力」の算出方法は全課題一律にしない。
単純な全員合算では「平凡な20人が精鋭4人に必ず勝つ」ことになり頭数一辺倒に戻るため、
**課題ごとに集計型を持たせる**。集計型は4種類：

| 集計型 | 算出方法 | 適用する課題の例 | 人数の効き方 |
|---|---|---|---|
| **加算型** | 該当スキル持ち全員の単純合算 | 採掘量、採取、運搬 | 頭数が素直に効く。経済・補給コストとの勝負 |
| **席数型** | 上位 N 人（席数）のみ寄与。**席数は課題側・環境で決まる**。戦闘は前衛席/後衛席に分解（§7） | 戦闘（狭隘=前2+後2、大空洞=前6+後6）、罠処理（2席） | 席数までは増員が有効、超過分は無意味 |
| **代表型** | 最高値の1人が基準。2人目以降はわずかな補助ボーナスのみ | 古代語解読、鑑定、交渉 | 専門家1人の質がすべて。数は不要 |
| **最弱連動型** | **最低値の1人**が基準＋人数ペナルティ | 隠密行動 | 増員するほど不利。少数精鋭が必須 |

- 集計型と席数は遠征データ側で定義する（データ駆動）
- この仕組みにより「遺構階の調査＝戦闘前2後2＋学者1人＋残りは荷物持ちが有効、
  それ以上の増員はコストだけ増える」といった**遠征ごとの適正人数・適正構成**が
  データから自然に導かれる

### 8.4 成否判定（確定事項）

- 課題ごとに、§8.3 の集計型で算出したパーティ該当能力と課題値から成功率を算出。
  **比率式**を採用（能力のスケールが変わる浅層〜最深部で係数の再調整が不要）:

```
課題成功率 = clamp(50% + 50% × (R − 1), 5%, 95%)   ただし R = パーティ該当能力 ÷ 課題値
```

- 目安: 課題値ちょうど（R=1.0）で50%、1.5倍で75%、1.8倍で90%。適正編成の想定は R≈1.5〜1.8
- 全課題の結果から総合成果を段階評価（大成功 / 成功 / 部分成功 / 失敗）
- 回収量・調査品質は成果段階と残り運搬力・専門スキルで決まる
- 道中の遭遇は階層危険度（§15.4）で別途発生し、負傷・食料損失・撤退などをもたらす。
  遭遇の解決は**全自動**。行動方針・性格・斥候・戦力から回避/戦闘/撤退が自動選択される
- 過剰戦力なら安全だが利益率が悪く、ギリギリなら効率的だがリスクが高い、という
  **経営判断のジレンマ**を全系統で維持する

## 9. 経済

- 通貨は1種類（ゴールド）
- **収入**: 依頼の固定報酬、回収品の換金、（拡張: 施設収入）
- **支出**: 冒険者への報酬分配・基本給、食料（派遣時）、施設維持費、契約料（雇用一時金）、違約金、蘇生費
- 毎ターン終了時に収支を精算。赤字が続くと倒産リスク
- 画面に常に「残高」「1ターンあたりの固定費」を表示し、収支感覚を持たせる

### 9.1 給与体系（確定事項）

**報酬分配が主、継続的な基本給は副次的**という配分にする。

- **報酬分配**: 遠征で得た報酬（固定報酬＋回収品の換金額）の一定割合を、
  その遠征の参加メンバーに分配する。冒険者の主収入はこちら
- **基本給**: 毎ターン少額を全所属メンバーに支払う（拘束料・生活保障のイメージ）
- **死亡中も基本給は支払う**。蘇生費を惜しんで放置しても維持費はかかり続ける。
  見込みがなければ死亡中に解雇して損切りしてもよい（その場合のみロスト）

この体系の狙い:

- 「抱える」のは比較的安く、「動かす」と取り分が割れる
  → 大所帯ギルド自体は成立するが、**1回の遠征に何人送るかが損益に直結**する
- 稼げない遠征に人を出すと分配で赤字になり得る一方、待機させ続けても基本給で薄く出血する
  → 手持ち人材の稼働率が経営指標になる

**分配方式: 頭割り（確定事項）**

- 遠征報酬のうち冒険者への分配分を、参加メンバーで均等に頭割りする
- 能力・貢献度比例に**しない**理由: 強いキャラほど取り分が増える方式だと
  「キャラを成長させると人件費が上がる＝育てたくない」という逆インセンティブが生まれるため。
  シミュレーションとしての面白みより面倒さが勝つと判断（設計判断として記録しておく）
- 失敗時は「得た報酬」がないため分配も発生しない。違約金はギルドが負担する
- 留意点: 頭割りのため、キャラの強さは分配額に反映されない。**優秀な人材の対価は
  契約料と基本給の傾斜（応募時の能力に応じて決まり、成長では上がらない）で表現する**。
  こうすれば「育てるほど得」が保たれる

## 10. 施設（投資先）

| 施設 | 効果（初版案） |
|---|---|
| 訓練所 | 待機中の冒険者が少しずつ経験値を得る |
| 医務室 | 負傷の回復日数を短縮 |
| 酒場 | 応募者の質・数が向上（珍しい種族・職も来やすく） |
| 受付拡張 | 同時遠征数 +1 |
| 倉庫 | 回収品の保管量増・相場を見て売るなど（拡張寄り） |
| 前線キャンプ | 迷宮内の中継拠点。深階への移動日数を短縮（拡張候補。§16） |

各施設はレベル制（Lv1〜3）。建設費＋毎ターン維持費。

## 11. 名声とギルドランク

- 名声は 依頼の成功（成果段階で増分が変わる）と**未踏階の踏破・主の討伐**で増え、依頼失敗で減る
- 名声の累計でギルドランクが E → D → … → S と昇格（勝利条件ではなく進行ゲート）
- ランクが上がると: 高難度の依頼が届く / 同時遠征数が増える / 応募者の質が上がる（§5）
- 攻略（到達階層）と経営（ランク）の2軸が進行度になる。深く潜るには人材と資金が要り、
  良い人材と依頼は名声が連れてくる——両輪を回す構造

## 12. 画面構成（ブラウザ / 初版）

SPA・1画面ベース。タブまたはペインで切り替え：

1. **メイン（ギルド）**: 残高・名声・ランク・到達階層・日付、今日のイベントログ、「日を進める」ボタン
2. **ダンジョンマップ**: 踏破済みの階と既知資源・主の位置。遠征目標の起点となる画面
3. **依頼掲示板**: 外部委託の一覧（課題・対象階・人数条件・報酬・期限）、受注操作
4. **冒険者一覧**: 所属メンバーの種族・性格・能力・スキル・特性・状態、応募者リストと雇用
5. **遠征編成**: 目標設定とパーティ編成・前衛後衛割り当て・補給・行動方針。**本作の主戦場**
   （派遣後は指示不可のため、意思決定はすべてここに集約される）。
   課題ごとの成功率見込み（席の埋まり具合・前衛不足・無駄人員が見える形で）・遭遇危険度・
   利益見込み（報酬 − 分配 − 食料）・運搬力の残りをリアルタイムに表示し、試行錯誤を快適にする
6. **施設**: 建設・アップグレード

**帰還報告（方向性確定、詳細は後日）**

- 帰還時のリザルトは**概要1枚**（成否・報酬・負傷/死亡・回収品のサマリ）をまず表示し、
  詳細（道中の遭遇ログ、課題ごとの判定内訳など）はクリック/タップ/キー操作で
  ドリルダウンして見られる2層構造とする
- 全自動派遣ゆえに帰還報告は体験の山場。ログの粒度・演出は他のシステムが固まってから詰める

グラフィックは初版ではテキスト＋簡易UIで十分（数値管理ゲームなので情報の見やすさを優先）。

## 13. 技術方針

- **プラットフォーム**: ブラウザ（Web技術）
- 想定スタック: TypeScript + 軽量フレームワーク（React or Svelte、要決定）+ Vite
- サーバ不要の完全クライアント動作。セーブは `localStorage`（JSON1本のステート）
- ゲームロジックはUIから分離した純粋関数群にする（テストとバランス調整シミュレーションが容易になるため）
- 乱数はシード指定可能にする（テスト・デバッグ用）
- 判定式・遭遇テーブル・階データ・応募者生成テーブルはデータ駆動にし、
  バランス調整をコード変更なしで回せるようにする

## 14. スコープ定義

### MVP（最初に作る範囲）

- ターン進行（1日単位）と収支精算
- ダンジョン: 浅層10階＋中層入口。主2体（5F・10F）。**MVPの勝利条件は10Fの主討伐**
- キャラクター: 能力値6種＋スキル10種程度＋特性数個。種族3種（人間/エルフ/ドワーフ）、
  性格は1タグ（行動傾向の軽い補正のみ）。職業肩書き6種（戦士/斥候/学者/荷物持ち/採掘師/治癒師）
- 雇用: 応募者リスト（7ターン更新・名声連動の質分布・契約料自動算出）
- パーティ: **最大人数は最初から20人対応**。人数コストは「経済」「補給・運搬」「遭遇」の3系統
  （統率は後回し）。前衛/後衛の2列制と「有効後衛 ≤ 前衛×2」ルールを実装
- 派遣は全自動解決。行動方針は3段階プリセット（慎重/標準/強行）＋性格1タグの揺らぎ
- 遠征: 自主遠征（攻略/採掘/調査）＋依頼（討伐/納品/調査）。課題リスト式・集計型4種を最初から実装
- 遭遇イベント: 階層危険度→遭遇表のシンプルな実装（負傷・食料損失・撤退・死亡）
- 状態異常ラダー: 健康/軽傷/重傷＋死体3段階（健全/損傷/白骨）の6段階に簡略化。
  地上施設での蘇生（割高）と自前術者による割引、全滅時の降霊術（大金）を実装。
  **救出遠征・ダンジョン内蘇生・灰以降の死体状態はMVP外**
- 給与: 報酬分配（頭割り）＋基本給。死亡中の基本給支払いと損切り解雇も実装
- 装備: 3スロット（武器/防具/アクセサリー）。店購入＋ドロップ。アクセは耐性系数種。回復薬1種
- 帰還報告: 概要1枚＋詳細ドリルダウンの2層構造（演出は最小限）
- 施設: 2種類（受付拡張・医務室）
- 敗北条件（倒産）とランクE→C
- localStorage セーブ / ロード

### MVP に入れないもの（拡張候補）

### 15.4 判定・遭遇の初期係数（たたき台）

`tools/encounter_sim.py` で検証済み。個人の課題能力 = 関連能力値 + 関連スキルLv×2
（序盤の平均像 ≈ 13）を基準スケールとする。

**判定（§8.4 の比率式）**: R = パーティ該当能力 ÷ 課題値、成功率 = clamp(50% + 50%×(R−1), 5%, 95%)

**遭遇**:

```
日次遭遇率     = 階層危険度 × (1 + 0.05 × (人数 − 4)) × (1 − 斥候軽減)
斥候軽減       = min(60%, 最良斥候の斥候スキルLv × 6%)      … 代表型
主クラス遭遇率 = min(35%, 5% + 1.5% × (人数 − 4))           … 遭遇発生時の内訳
主クラス敵戦力 = 通常敵の2.5倍
```

| 階層危険度 | 値（1日あたり基礎遭遇率） |
|---|---|
| 浅層上部（1〜5F） | 10% |
| 浅層下部（6〜10F） | 20% |
| 中層（11〜25F） | 35% |
| 深層以降（26F〜） | 50% |

- 遭遇も §8.4 と同じ比率式で解決（パーティ戦闘力[席数型・前衛後衛] vs 敵戦力）。
  敗北時は負傷・死亡判定のうえ任務中断（＝遠征失敗）
- **通常敵は適正編成なら安定して勝てる強さ**（敵戦力 ≈ 戦闘課題値の0.75倍目安）に設定し、
  消耗を与える役に留める。**大所帯の実リスクは主クラス遭遇率の上昇**に集約させる
  （人数で頻度はマイルドにしか増やさない。§6.3 の確定方針）

**検証結果（人数を2〜20人で振った場合の期待利益ピークと死者率）**:

| 遠征 | 適正人数（利益ピーク） | ピーク時: 成功率/利益 | 20人時: 利益/死者率 |
|---|---|---|---|
| 浅層上部討伐（危険度10%・席4） | 3人 | 94% / +97G | −153G / 1.5人per100件 |
| 浅層下部討伐（危険度20%・席4） | 4人 | 75% / +94G | −314G / 6.3 |
| 鉱脈階採掘（危険度20%・席4・加算型） | **10人** | 83% / +174G | −311G / 9.4 |
| 中層討伐（危険度35%・席6） | 6人 | 68% / +115G | −520G / 13.9 |

- 遠征ごとに異なる適正人数がデータ側から生まれること（§6.2 の設計目標）、
  少人数は成功率・死者率で、過剰人数は分配と主クラス遭遇で罰されることを確認済み
